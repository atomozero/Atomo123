# Examples

`Atomo123_esempio.ascd` — a two-sheet workbook in Atomo123's native
format, meant to be opened right after installation to get a quick
feel for what the app can do. Shows:

- formulas, including cross-sheet references
- currency formatting, colors (text/background/border), alignment,
  underline, text wrap
- merged cells, custom column width/row height
- frozen panes and AutoFilter
- sheet tab color
- a cell comment and a hyperlink
- an embedded bar chart

Generated by `ui/examples/generate_demo.cpp` (`make demo` in `ui/`,
which writes `ui/examples/atomo123_demo.ascd`, not version-controlled)
— this copy under `examples/` is the one distributed with the repo.
